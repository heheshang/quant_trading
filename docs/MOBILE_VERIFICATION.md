# 移动端（<768px）逐页核对清单

> 用途：在 `npm run tauri dev` 启动后，把窗口/浏览器缩小到手机宽度（<768px，如 375px），逐页核对以下要点。
> 目的：验证移动端布局/表格/弹窗/导航是否适配，无横向溢出。

## 通用检查项（每页都看）

- [ ] **导航**：点头部汉堡 → 底部按钮弹出**左侧抽屉**（不再是固定侧边栏）；选中菜单跳转后抽屉自动关闭；桌面宽度（≥768px）恢复为固定可折叠侧边栏。
- [ ] **表格**：宽表格出现**横向滚动**（在卡片内滑动），不被裁切、不把整页撑宽。
- [ ] **卡片/栅格**：多列卡片**从上到下堆叠**为单列（`el-col` 全宽），不横向挤压。
- [ ] **弹窗**：`el-dialog`/`el-message-box` 宽度约 92%，不超屏、可滚动。
- [ ] **表单**：表单控件不溢出；标签宽度收窄。
- [ ] **无横向滚动**：整页不出现左右滑动（`body overflow-x hidden`）。
- [ ] **暗色模式**：右上角图标切换暗色，文字/卡片/表格/图表/弹窗/抽屉均正常。
- [ ] **无遮挡**：顶部进度条、卡片阴影等正常，无元素被截断。

## 逐页核对

### 登录页
- [ ] UI 居中、输入框不溢出、按钮可达。
- [ ] 背景/卡片在暗色下协调。

### 仪表盘 Dashboard
- [ ] 统计卡（StatsCard）堆叠为单列。
- [ ] 图表明细（权益/回撤/持仓）单列展示；图表容器 `height` 不强制过高。
- [ ] 实时行情表可横向滚动。

### 策略管理 Strategy
- [ ] 策略表格横向滚动。
- [ ] 展开/表单弹窗 92% 宽、可滚动。
- [ ] 状态标签、按钮不溢出。

### 回测 Backtest
- [ ] 配置表单在窄屏可用。
- [ ] 绩效图表单列、图例不遮盖。
- [ ] 结果表格横向滚动。

### 交易 Trading
- [ ] 纸面/币安下单表单不溢出；价格/数量输入可达。
- [ ] 持仓/挂单表格横向滚动。
- [ ] 币安面板同样适配。

### 风险 Risk
- [ ] 风险指标卡堆叠。
- [ ] 告警表格横向滚动。
- [ ] 事前风控表单可用。

### 监控 Monitor
- [ ] 指标卡堆叠；指标图表单列。
- [ ] 告警面板/日志表格横向滚动。
- [ ] 阈值配置表单可用。

### 系统设置 Settings
- [ ] 各选项卡内容在窄屏可读，表单不溢出。
- [ ] 数据库/Redis/交易所/安全等表单控件可达。

### 个人账户 Profile
- [ ] 信息卡堆叠；安全设置（密码/2FA）表单可用。

### 币安 Binance
- [ ] 余额表横向滚动；实时行情面板单列；下单表单不溢出。

### 测试页 Test
- [ ] 无溢出、控件可达。

## 记录方式

逐页勾选后，如发现具体问题，记录：
```
页面 / 元素 / 视口宽度（如 375px） / 现象（溢出/被裁/遮挡） / 建议
```

> 说明：此清单为**人工在真机/浏览器核对**使用；CLI/无头环境无法启动 Tauri GUI 或截取真实页面。
